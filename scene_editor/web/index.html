操作の流れ

①プロジェクトを選択 → ②Clipごとのプロンプト・画像・Durationを設定 → ③「全Clipを保存」 → ④ComfyUIの別タブで実行。
既存プロジェクトの scenes.json は最初にそのまま読み込みます。保存後、ComfyUI の Scene Loader が更新を検知します。

注意：Clipを1つだけ生成する場合は、ComfyUI側の Use Clip Total / Bypass も従来どおり1Clipに設定してください。Scene Editorの有効・無効だけでは生成分岐を切り替えません。
